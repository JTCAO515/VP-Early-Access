## 1. Demo 核心目标

用户应在 1–2 分钟内理解：

1. Chatbot 如何通过追问理解旅行需求；
2. Trip Canvas 如何承接并组织旅行结果；
3. Copilot 如何通过长期对话形成用户记忆和旅行画像；
4. Explore 如何完成城市、POI 与执行工具的发现；
5. VisePanda 如何把行程检查、确认、下一步和恢复路径组织在一个产品内。

产品宣传顺序：

```text
Chatbot / Trip Canvas
  -> 用户长期记忆与画像
  -> Explore / 多执行工具
  -> 行程模拟器：导入、检查、确认
```

## 2. 16:9 浏览器框架

## 4. Ask VisePanda / Trip Canvas

Ask 页面统一采用：

- 左侧：Trip Canvas；
- 右侧：Chatbot；
- 对话和 Canvas 内容同步切换；
- Canvas 变化先展示，再由用户确认；
- 预订、叫车、购买按钮只展示跳转能力，不开启真实交易。

### 4.1 New Chat

- Chat 显示城市、时间、预算、兴趣和限制的输入提示；
- Canvas 显示“尚未创建行程”；
- 推荐输入：上海三日游、上海到北京、上海餐厅、检查已有攻略。

### 4.2 上海三日游

Chat 第一轮：

> 用户：帮我安排上海三日游，节奏不要太赶。我喜欢建筑、本地美食，也想看夜景。

> VisePanda：你更想多逛街区，还是多看地标？每日预算大约多少？

Chat 第二轮：

> 用户：多逛街区，预算中等，晚上想看浦江夜景。

底部显示“正在生成 Trip Canvas”。

Canvas：

- Day 1：外滩、豫园、本帮午餐、浦江夜景；
- Day 2：武康路、衡复风貌区、咖啡馆、精品餐厅；
- Day 3：西岸美术馆、新天地、晚餐；
- 每日包含交通、预计时间、餐厅、预订提醒、预算和下一步。

### 4.3 上海到北京

Chat 追问：

- 交通预算；
- 出发时间；
- 行李；
- 酒店预算和风格；
- 是否需要灵活取消。

Canvas：

- 高铁与航班对比；
- 行程时间、模拟价格、机场/车站交通；
- 王府井、前门、国贸酒店对比；
- 房型、早餐、取消政策、到景点时间；
- “前往官方渠道”“查看酒店”静态跳转反馈。

### 4.4 北京豪华酒店

- 景观、早餐、安静程度、接送、灵活取消和同行人数追问；
- 酒店比较列表；
- 位置、房型、取消政策、交通时间；
- 加入 Canvas 与预订跳转状态。

### 4.5 上海餐厅

Chat 追问：

- 当前定位；
- 人数和预算；
- 忌口、过敏与辣度；
- 菜系和排队接受度。

Canvas 展示餐厅、区域、距离、价格、菜系、地址和团购跳转。

点击“查看菜品”打开抽屉：

- 菜品名称；
- 图片位；
- 口味；
- 原料和过敏原；
- 推荐搭配；
- 价格和团购套餐；
- 加入行程。

### 4.6 攻略验证

用户提供：

- `China Trip.pdf`；
- Reddit 攻略链接；
- 文字行程；
- 订单截图。

Canvas 显示：

- 合理节点：外滩晨间步行；
- 合理节点：下午游览豫园；
- 不合理节点：晚餐后上海前往西安；
- 原因：末班高铁、转场和入住时间冲突；
- 接受、修改、拒绝和确认更新操作。

## 5. Copilot / 长期记忆用户画像

Copilot 是 Demo 的重点宣传区块。

### 5.1 画像维度

- 旅行强度；
- 每日预算；
- 步行承受度；
- 起床与出发时间；
- 酒店和交通偏好；
- 餐饮偏好；
- 忌口与过敏；
- 兴趣主题；
- 同行人；
- 无障碍需求；
- 风险偏好；
- 预订灵活度。

### 5.2 记忆来源

- 最近对话；
- 用户确认的 Canvas 变化；
- 收藏和拒绝的 POI；
- 上传的攻略；
- 过往旅行；
- 用户主动设置。

### 5.3 自适应示例

- 上海 Day 2 步行减少 2.4 km；
- 增加一次短途叫车；
- 晚餐切换为无花生菜单；
- 删除重复建筑景点；
- 延后出发时间；
- 酒店筛选调整为安静房型。

操作：查看 Canvas 变化、接受、调整画像、忘记偏好、查看记忆来源。

Michael Turner 的模拟画像：

| 维度 | 判断 |
| --- | --- |
| 人群 | 美国中产、中年男性、独立旅行者 |
| 旅行节奏 | 舒适但不松散；每天约两个主要节点 |

| 风险偏好 | 谨慎；重视取消政策、备用方案和官方渠道 |
| 支付 | 优先境外信用卡，同时准备移动支付和现金备用 |

### 6.5 记忆判断的透明度

每项记忆显示：

- 来源：哪一次对话、哪个 Canvas 或用户设置；
- 状态：用户确认 / 系统推断；
- 置信度；
- 最近更新时间；
- 影响了哪些行程建议。

### 6.6 编辑交互

页面提供醒目的 `Edit profile` / `编辑画像` 按钮。

点击后进入预制编辑状态：

- 修改预算区间；
- 调整旅行强度；
- 修改每日步数；
- 添加或删除兴趣；
- 修改酒店和交通偏好；
- 修改过敏原；
- 将推断改为确认；
- 忘记单项记忆；
- 暂停长期记忆；
- 保存并预览 Canvas 如何变化。

保存后展示反馈：

> Profile updated. Future suggestions will use the new pace and budget.
